# 🎲 Dice Game - React + Vite

A simple and fun dice game built with **React** and **Vite**. Roll the dice, accumulate score, and enjoy the game mechanics!

---


## 🚀 Features

- 🎲 Roll dice animation
- 🔢 Score tracking
- 🧠 Game logic with condition handling
- ⚡ Built with React + Vite for fast performance
- 📱 Responsive design

---

## 🛠️ Tech Stack

- React
- Vite
- JavaScript (ES6+)
- CSS
